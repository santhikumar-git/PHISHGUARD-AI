# 🛡️ PHISHGUARD AI

### Educational Email Security & Phishing Risk Analysis Platform

**PHISHGUARD AI** is a Python-based cybersecurity project that analyses email text and highlights suspicious characteristics using rule-based detection.

> Version 1.0 is an educational prototype. It does not use a trained AI model, and its risk score is not a probability or proof of phishing.

## ✨ Features

- Email text analysis
- Suspicious phrase detection
- Urgent language identification
- URL presence detection
- Heuristic risk scoring
- LOW, MEDIUM and HIGH risk categories
- Detection findings with explanations

## 🧰 Technology Stack

- Python
- Streamlit
- Regular Expressions

## 🚀 Run Locally

1. Clone this repository:

   `git clone https://github.com/santhikumar-git/PHISHGUARD-AI.git`

2. Open the project folder:

   `cd PHISHGUARD-AI`

3. Install the dependency:

   `python -m pip install streamlit`

4. Run the application:

   `python -m streamlit run app.py`

## 🔍 How It Works

The application checks submitted email text against configured warning patterns and assigns a heuristic risk score.

The results help users identify messages that may need further review.
